When building UI, don't jump straight to raw functionality. Provide context first.

**Why:** User said "너무 딱딱하네" (too stiff) when simulator launched directly without introduction. Referenced https://jihoonjeong.github.io/ai-ludens/ as the desired aesthetic — minimalist, typography-focused, generous whitespace, content-first.

**How to apply:**
- Landing pages before tools. Give users context before interaction.
- Dark theme, monochromatic base, color only for data/accents.
- Large typography for headings, generous vertical spacing.
- When adding new features/tabs, update landing to introduce them (e.g., geopolitical section was added to landing after geo tab was built).
